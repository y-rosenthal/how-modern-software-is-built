How Modern Software Is Built (in 2026)

The architecture of websites, mobile apps, installed programs, and embedded devices, explained for business students who will be building products with Claude Code and learning Python at the same time.

Audience Business students, little technical background Format Lecture with live demos and review questions Sessions 5 × 75 minutes

How to use this document

  • Each session is designed to fit in 75 minutes. Every section carries a time budget tag such as 10 min. The budgets add up to about 70 minutes, leaving 5 minutes for the review questions and spill-over.
  • Keywords students should be able to define are highlighted like architecture. Every keyword is collected in Appendix A with a short definition and a link back to where it is introduced.
  • Review questions appear at the end of each session in a yellow box marked with a question mark. The questions and their answers are repeated in Appendix B.
  • Callouts in grey are instructor notes, analogies you can use in class, and suggested live demos. Demos are optional; each session works as a pure lecture. Callouts with a teal edge labelled "In the age of AI" say how AI-assisted development changes the point just made.
  • Diagrams are drawn so that you can talk through them left to right or top to bottom. Each caption states the single point the picture is making.

Software architecture sounds like a topic for engineers, but the decisions it describes are business decisions in disguise. Whether a product can handle a spike of customers on launch day, what it costs to run every month, how quickly a new feature can ship, what happens when a server fails at 2 a.m., and how a customer's password is protected are all consequences of architecture. When you use a tool like Claude Code to build a product, you will be asked to make these decisions, or at least to approve them. This module gives you the vocabulary and the mental models to do that well.

The material is deliberately cumulative. Session 1 asks what software is written in and how that choice is made. Session 2 starts with a web page that is nothing more than a text file on your laptop. By the end of Session 5 you will be able to sketch the architecture of a company like Airbnb or Shopify, explain what "Sign in with Google" actually does behind the scenes, and describe how a phone app, a desktop program, and a smart thermostat all talk to the same servers.
